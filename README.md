# 鳄鱼派思想

这是“像鳄鱼一样思考”项目的研究整理仓库，目标是把作者关于宏观、政策、产业、市场参与者、技术信号、长期价值和实际行动的公开文章，整理成可复习、可检验、可继续补充的思想材料。

## 从哪里开始

建议按以下顺序阅读：

1. [作者如何判断股市：核心思想](01-核心报告/作者如何判断股市_核心思想.md)
2. [作者思想演化报告](01-核心报告/作者思想演化报告.md)
3. [全库思想演化综合](01-核心报告/全库思想演化综合.md)
4. [宏观研判：每日复盘任务与学习路线](01-核心报告/宏观研判_每日复盘任务与学习路线.md)

## 目录

- `01-核心报告/`：核心思想导读、阶段演化、全库综合，以及把思想转成每日复盘和学习计划的任务文档。
- `02-研究方法与证据/`：覆盖口径、研究统筹、审阅交接和重点事件材料。
- `03-分批阅读记录/`：分批阅读阶段的综合札记和执行证据，保留研究过程中的上下文与限制。

## 研究边界

- 研究覆盖口径为 **436 篇有可用正文的唯一文章**；另有两份平台违规删除提示，不计入可读正文。
- 本仓库是对作者公开文章的研究整理，不是行情回测、收益率统计或预测准确率评价。
- 文档中的“实际行动”只在作者原文明确自述时成立；计划、条件建议、对过去行动的回述和研究者解释均按原文边界区分。
- 报告保留了原研究中的证据日期、文章 ID 和行号。原始文章 MD、PDF、HTML、CSV 及图片没有随本仓库发布，因此部分指向本地原文的链接只在原研究工作台中可用。
- 这套材料用于学习研究，不构成投资建议。

## 研究方法

阅读时优先看原文连续上下文，再看校准行号的阅读记录和阶段综合；机器检索只用于定位。对每个重要变化，分别追踪：原判断或规则、新信息或反例、作者说明的原因、判断变化、实际行动、后续回应，以及仍未闭合的部分。
